# Desktop apps from outside the distro's own repos, for scripts/setup/apps, on
# every machine. apps-<machine>.txt adds apps for one machine, as chosen at
# `chezmoi init`, in the same format.
#
# Columns: what to check, then how to install it on Fedora and on Arch. What to
# check is a command or a path (/...); several, comma separated, mean any one
# of them will do. A route is one of:
#
#   dnf:PKG,...             Fedora packages, from repos already set up
#   rpm:URL,...             RPMs to download and install ({fedora} is the release)
#   repo:PKG,...@REPOFILE   add a repo (a URL, or a file in this checkout), then
#                           install its packages
#   json:URL@FILTER         the RPM whose URL the jq FILTER picks from URL's JSON
#   pacman:PKG,...          Arch packages
#   aur:PKG,...             AUR packages, built with paru
#   none                    nothing to install on this distro
#   -                       no route on this distro; install it by hand
#
# check  fedora  arch
